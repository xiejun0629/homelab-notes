## 想换成企业微信 / 钉钉机器人？
把 `/opt/dashboard/notify.json` 的 `channels` 改成（不需要重启，30 秒内自动生效）：

```json
"channels": [
  { "type": "webhook", "url": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key" }
]
```

钉钉：`{"type":"webhook","kind":"dingtalk","keyword":"告警","url":"https://oapi.dingtalk.com/robot/send?access_token=xxx"}`

Gatus 那半边换通道要改 `/opt/gatus/config/config.yaml` 的 `alerting` 段（Gatus 也支持 custom/webhook）。
