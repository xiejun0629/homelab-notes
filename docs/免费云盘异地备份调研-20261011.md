# 免费云盘做异地备份：调研结论（2026-10-11）

## 直接结论
**没有任何一家的免费额度能装下你 300GB 的照片。** 免费层最多 10–20GB，只够放"配置 + 数据库 + 重要文档"这类几个 GB 的东西。

## 分两件事看
### A. 小体积关键数据（配置、数据库、重要文档，几 GB）→ 免费完全够
| 方案 | 免费额度 | 说明 |
|---|---|---|
| **Backblaze B2** ⭐ | 10GB 永久 | S3 兼容，restic/rclone 原生支持，下载免费额度 = 月均存储×3 |
| **Cloudflare R2** | 10GB/月 | 下载永久免费；按天峰值向上取整，大陆域名有时被污染 |
| 七牛云 Kodo | 10GB 永久 | 国内速度快，但只适合放小文件 |
| Oracle 永久免费 | 20GB | 额度最大，但必须绑卡，闲置可能销号，超量会删数据（有风险） |
| 香港 VPS | 约 20GB 空余 | 你已经有了，放配置/数据库异地副本最省事，不用注册任何东西 |

### B. 照片/视频全量（100–300GB）→ 没有免费方案
- 阿里云盘免费实际约 1GB（且每月下载流量仅 10GB）、夸克新用户 10GB、MEGA 20GB、Google Drive 5GB、OneDrive 5GB —— 都不够。
- 123 云盘 2TB 看着香，但**超过 10GB 的单文件只算进 50GB 的"专业空间"**，而 restic 仓库必然是大文件 → 不适合。
- **Storj 2026-07-01 改版后已无永久免费**（有最低月消费，欠费 45 天删数据）。
- **rclone 官方不支持**阿里云盘/夸克/百度/123/天翼/移动云盘/115，只能靠 AList/OpenList 转 WebDAV 这类非官方接口，随时可能失效 → 不适合做自动备份。
- 最便宜的正规方案：**Backblaze B2 付费约 $6.95/TB/月**（300GB ≈ 每月 15 元人民币），配 restic 客户端加密 + 去重，实际占用通常更小。

## 推荐落地组合
1. **主力**：restic + Backblaze B2（先建 10GB 免费账号跑通，不够再升付费）
2. **第二副本**：香港 VPS 的 20GB 空余（放配置/数据库/最珍贵的照片精选）
3. **本地**：NAS 保留一份（3-2-1 原则里的"1"）
4. 照片每周日 03:00、配置/数据库每天 03:00 自动跑，脚本里用 `flock -n` 防重入，每月 `restic check --read-data-subset=5%` 抽查

## 完全免费能做的版本（不花一分钱）
- 配置 + 数据库 + 记账数据 + 笔记 + 精选照片（< 10GB）→ **Backblaze B2 免费层**
- 剩下的大头照片 → 暂时用移动硬盘做离线副本（3-2-1 里的"离线一份"），等以后愿意花钱再上 B2 付费

## 需要你自己实测的
- B2 / R2 在你这儿的上传下载速度（家宽出口 203.0.113.10，走香港 VPS 会快一些）
- 免费额度的口径各家会变，落定前建议再看一眼官方定价页
