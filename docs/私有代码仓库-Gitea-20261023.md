## 常用操作
```bash
# 容器
cd /opt/gitea && docker compose up -d          # 启停
docker logs --tail 50 gitea                    # 日志

# 用户管理（需 -u git）
docker exec -u git gitea gitea admin user list
docker exec -u git gitea gitea admin user create --admin --username <name> --password '<pw>' --email <mail> --must-change-password=<REDACTED>

# 手动备份
/opt/gitea/backup.sh

# 手动推送备份仓库
cd /opt/homelab-git && git push --mirror gitea
```
- HTTPS 克隆地址：`https://example.com/user/homelab-backup.git`（用 user/密码认证；**SSH 克隆未开启**，如需再开 frp TCP 端口）。
- 仓库默认私有；已关闭注册（DISABLE_REGISTRATION=true），未登录访问会跳登录页。

## 恢复（新机器）
1. 恢复 `.223:/opt/gitea/data`（或从 NAS `/nas/backups/gitea/` 最新 dump 恢复 DB/用户/配置）。
2. 起容器；恢复 `20-git*.conf` 与 NPM 证书（或重新 certbot --expand）。
3. frpc 域名列表加 git 子域；DNS A 记录指向 VPS。
4. 若仓库丢失：`cd /opt/homelab-git && git push --mirror gitea` 重新灌入。
