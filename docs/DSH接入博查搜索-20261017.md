# DSH 接入博查搜索（MCP）· 2026-10-17

## 是什么
- 给 DSH（`.223` 上的 agent 程序，Web UI 在 127.0.0.1:19387）增加联网搜索工具 **`mcp__bocha__search`**，agent 可直接调用博查搜索 API（中文长摘要、单次 0.3–0.5s）。
- 与 Open WebUI 的搜索切换互不影响：那边是把 Web 界面搜索引引擎换成博查；这边是给 agent 加一个工具。

## 接入方式（为什么用 MCP 而不是原生 provider 插件）
- 先写的是 DSH 原生 search provider 插件（`/root/plugins-src/dsh-bocha/lib/provider.js`，provider id `bocha`），但实测 **运行中安装无法激活**：DSH 的模块解析表在启动时固定，启动之后新装的 host 插件 import 不到 `@deepseek-ai/*` 依赖，必须重启整进程才生效（会中断当前对话、旧 GUI token 失效）。
- 因此改走 **MCP 配置型 bundle**：只往配置里 insert 一条 `@deepseek-ai/dsh-mcp-client`（DSH 自带包、可原生解析），再配一个独立 Node stdio MCP server 调博查 → **无需重启，安装即热生效**。
- 原生 provider 代码保留着（`/root/plugins-src/dsh-bocha`），将来重启 DSH 想要原生 `web_search` provider 时可切回。

| 工具参数 | `query`、`count`（1–10，默认 8）、`freshness`（noLimit / oneDay / oneWeek / oneMonth / oneYear） |

## 验证
- MCP 协议单测（initialize + tools/list + tools/call）：**505ms**。
- 本 agent 实测：问"上海今天天气"→ 返回 2026-10-17 阴 27/23℃ + 未来一周逐日预报；顺丰三季报查询 → 返回 2023 三季报点评 + 2026 Q1 数据（纯关键词长查询召回一般，属搜索 API 正常波动）。
- `plugin_manager` 安装结果 `application: applied`，无 warning；`Tool.listTools` 能看到 `mcp__bocha__search`，系统提示里出现 "MCP server: bocha"。

## 维护 / 注意

## 追加（2026-10-24 13:1x）：博查额度用完后自动切换 DeepSeek 官方搜索
### 背景
DeepSeek 开放平台已上线官方 Search / Fetch API（自研搜索引擎，与主 API 共用 Bearer Key）：
- 端点：`POST https://api.deepseek.com/v1/tools/search`，Body：`{"query","count"(1-50),"ori_question","localization","need_content"}`；
- 返回：`results[]`（title/url/snippet/summary/content/site_name/date/authority/rerank_score）；
- 计费：每 1000 次成功请求 5 元（失败/无结果不计费）；2026-11-01 00:00 前免费，之后按次收费。
- 当前博查余额 ¥15.45（日均 ¥0.32，约 48 天用完）。
### 实现（DSH 搜索 MCP 插件改造）
- 插件：`/root/plugins-src/bocha-mcp/server.mjs`（零依赖 MCP server，工具名仍是 `mcp__bocha__search`，DSH 侧无需改配置）。
- 新增 provider 逻辑：
  - 默认 `SEARCH_PROVIDER=auto`：**博查优先；失败/HTTP 错误/额度用完时自动切 DeepSeek 官方搜索**；
  - 博查失败后熔断 10 分钟（`BOCHA_CIRCUIT_MS`），期间直接走 DeepSeek，避免每次都等博查超时；
  - `SEARCH_PROVIDER=bocha` / `deepseek` 可强制单一来源；
  - 工具新增可选参数 `provider`（auto/bocha/deepseek），可临时强制来源（已验证）。
- Key：DeepSeek Key 默认读 `/opt/projects-site/.deepseek-key`（可用 `DEEPSEEK_KEY_FILE` 覆盖）；博查 Key 仍读 `/root/.dsh/secrets/bocha.key`。
- 配置：`/root/plugins-src/bocha-mcp/cordis.patch.yml` 增加 DEEPSEEK_KEY_FILE、SEARCH_PROVIDER=auto（当前运行进程用代码默认值，下次 DSH 重启后走配置环境变量）。
- 生效：热重启 MCP 子进程后已生效（mcp-client 自动重连）。
### 验证（已实测）
- `provider=deepseek`：返回「DeepSeek 官方搜索搜索结果」（3 条，含标题/URL/发布时间/摘要）✅
