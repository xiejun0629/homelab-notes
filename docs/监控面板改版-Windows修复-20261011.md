# 监控面板改版 + Windows 节点修复（2026-10-11）

## 一、Windows .155 红灯（原因与修复）

**现象**：监控台「本机（Windows）」显示离线，gatus 的 `Windows .155（SSH）` 也亮红。

**根因**：Windows 上的上报脚本 `C:\Users\Administrator\lan-dashboard\win-agent.ps1` 被保存成了
**UTF-8 无 BOM**。Windows PowerShell 5.1 在没有 BOM 时按系统 ANSI 代码页（GBK）读取 .ps1，
中文标签被误解码后吞掉了后面的引号，脚本直接**语法报错**、无法启动：

```
At win-agent.ps1:395 char:50  Missing type name after '['
The string is missing the terminator: '.
```

（10-07 09:53 之前一直在正常上报，是常驻进程用的旧内存副本；重启后读到坏文件才停摆。）

**修复**：

1. `win-agent.ps1` 备份为 `win-agent.ps1.bak-20261011`，重写为 **UTF-8 with BOM**（内容一字未改）。
2. 语法校验通过、中文标签恢复正常，手工单次上报成功。
3. 计划任务 `LAN-Dashboard-Agent` 加固并立即启动：
   - 触发器：开机 + 每 10 分钟重复（防进程意外退出）
   - 多实例策略 `IgnoreNew`（不会重复启动）
   - 失败自动重试：999 次 / 每 1 分钟
   - 运行时间限制 `PT0S`（常驻不被杀）
   - 任务 XML 备份：`C:\Users\Administrator\lan-dashboard\task-backup-20261011.xml`
4. 现况：每 60 秒上报一次，四台机器全部在线。

## 三、Windows 温度终于有读数了（补充）

**为什么一直显示"未找到温度来源"**：

1. **LibreHardwareMonitor 0.9.x 不再提供 WMI 命名空间**（`root\LibreHardwareMonitor` 是
   老版 OpenHardwareMonitor 的做法），代理由此读不到任何传感器；
2. Ryzen 桌面平台**没有 ACPI 热区**，`MSAcpi_ThermalZoneTemperature` 同样不存在。
   → 两路都空，所以提示"未找到温度来源"。

**解决：改用 LHM 自带的数据服务（HTTP JSON），只在回环上读**

1. 在 LHM 配置里打开数据服务：加 `runWebServerMenuItem=true`（端口沿用已有的
   `listenerPort=8085`），重启 LHM 后 `http://127.0.0.1:8085/data.json` 返回 19 个温度传感器。
   - 配置备份 `LibreHardwareMonitor.config.bak-20261011`
   - 踩坑记录：第一次误加了重复的 `listenerPort` 键 → LHM 启动即崩（CLR20r3 /
     `System.ArgumentException` in `PersistentSettings.Load`）；已回滚，只用正确键名。
2. 代理 `win-agent.ps1` 的 `Get-Temps` 增加第三个来源：解析 data.json，按硬件分组
   （主板 / CPU / GPU / SSD），同名传感器去重取高值、过滤警告阈值项、每组件最多 4 个。
   - 备份 `win-agent.ps1.bak-20261011`（BOM 修复前）与 `win-agent.ps1.bak-0910`
   - 注意：该脚本必须存成 **UTF-8 带 BOM**，否则 PowerShell 5.1 按 GBK 解析会语法报错。
3. 安全：LHM 的 8085 监听在 `203.0.113.10`，已加入站阻止规则 `Block-LHM-Web-8085`
   （Windows 防火墙不过滤回环，代理照常读取），局域网访问不到。
4. 计划任务加固：`LibreHardwareMonitor-Elevated` 触发器 = 开机 + 登录 + 每 10 分钟，
   运行级别 Highest，多实例策略 IgnoreNew。

**结果**：本机卡片"CPU 温度"不再 N/A，温度传感器区显示
CPU 72.3 °C（Ryzen Tctl/Tdie）、GPU 61.6 °C、SSD 63.9 / 62.0 °C、主板 72.0 °C。
