## 二、修掉的真问题 1：证书续期会在 12-31 之后彻底失败
**原状**：`certbot renew` 两张证书**全部失败**——
- `example.com`（网站真正在用的那张）用的是 `manual` 认证 + 手工加 TXT 的钩子，默认模式直接 `exit 1` 并提示"需要人工添加 TXT，自动续期不可用"；
- 另一张 `example.com-0001` 用 `standalone`，但 80/443 都被 NPM 容器占着，必然失败。

也就是说：**12-31 一过，全站 HTTPS 会开始报证书错误**。

**为什么不能用原来那套自动 DNS 验证**：通配符证书只能用 DNS-01，而你的域名是在 **e8hk** 买的（虽然权威 NS 其实是 Cloudflare 的 becky/conrad，但你手上没有 Cloudflare 面板，拿不到 API Token），所以无法无人值守地自动加 TXT。

**改法（不需要你做任何事）**：改用 **HTTP-01 文件验证 + webroot**。
- 在 `.164` 的 NPM 里加了一个挑战目录 `location ^~ /.well-known/acme-challenge/ { root /data/acme-webroot; ... }`（写进 `1.conf` 与 `9-shared-hosts.conf` 的 80 端口 server 块，共 7 处）；
- 证书域名 = **目前真正有公网 A 记录的 6 个**：`example.com`、`memory.`、`photo.`、`dsh.`、`ledger.`、`video.`（其余 `con./music./novel./quant./game./files./nas./network.disk.` 都没有 A 记录，HTTP-01 无法验证，也不需要）；
- 证书名保持 `example.com` 不变 → **NPM 配置一行都不用改**；
- 结果：新证书 **2027-01-11 到期**，`certbot renew --dry-run` **演练成功**，`certbot.timer` 每天自动跑 → 以后自动续期，不用再管。

**代价（唯一一个）**：通配符 `*.example.com` 没有了。影响只有"内部才用、外网没解析的名字"（比如 `con.`、`network.disk.`）；你家主页里这些服务本来就是路径式（`/con/`、`/dns/`），所以实际没影响。
**以后新增子域名**：DNS 加好 A 记录后，在 .164 上跑一条命令即可扩容证书：
```bash
bash /root/add-subdomain-cert.sh example.com
```

## 三、修掉的真问题 2：.223 的 DNS 走 203.0.113.10，导致"偶发十秒级卡顿"
体检时发现公网访问**每 3 次里有 1 次慢到 10.8 秒**。分段计时定位：
- 绕过 DNS（直接打 VPS IP）→ **每次都稳定 0.30 秒**；
- 走 DNS → 偶发 `dns=5.35s`，甚至 8 秒超时。

根因：`.223` 的 `/etc/resolv.conf` 写的是 `nameserver 203.0.113.10`（`/etc/systemd/resolved.conf` 里也是），而 203.0.113.10 在国内会间歇性丢包/超时。**受影响的是跑在 .223 上的 Jellyfin、Gatus、DSH、录像入库等所有需要解析域名的服务**（我先前测"网站偶尔很慢"其实是这个）。

修法：`.223` 改走本机 unbound（`127.0.0.1`，分流配置：普通域名走阿里/腾讯 DNS，影视元数据域名走香港隧道）：
- `/etc/resolv.conf` = `nameserver 127.0.0.1` + `203.0.113.10` 兜底；
- `/etc/NetworkManager/conf.d/99-dsh-dns.conf`（`dns=none` + `rc-manager=unmanaged`）防止重启后被 NetworkManager 改回去；
- `/etc/systemd/resolved.conf` 里 `DNS=127.0.0.1`、`FallbackDNS=203.0.113.10 203.0.113.10`。

**效果**：公网首页 10 连测 = 0.30/0.31/0.32/0.31/0.33/0.36/0.30/0.31/0.35/0.30 秒，**没有一次超过 0.4 秒**。备份：`/root/resolv.conf.bak-*`、`/root/resolved.conf.bak-*`。
