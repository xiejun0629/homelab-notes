# 内网监控台：DeepSeek 余额 / 消耗卡片（2026-10-14）

## 做了什么
在 `.164` 的内网监控台（https://example.com/con/ ）概览卡片正下方，加了一张 **DeepSeek 余额** 卡片：
当前余额（低于 ¥5 变黄、低于 ¥2 变红）、今日消耗、昨日消耗、近 14 天消耗柱状图、最后更新时间。

## 数据从哪来
- DeepSeek 官方**只提供余额接口**（没有用量接口）：
  `GET https://api.deepseek.com/user/balance` + 头 `Authorization: Bearer <API Key>`
  返回 `{"is_available":true,"balance_infos":[{"currency":"CNY","total_balance":"14.63","granted_balance":"0.00","topped_up_balance":"14.63"},{"currency":"USD",...}]}`
- **消耗 = 余额差值**：采集脚本每次记一个余额点，当天「第一个点 − 最后一个点」就是当天花掉的钱。
- 采集脚本：`.164:/opt/dashboard/deepseek_balance.py`，每 15 分钟由 systemd 定时器 `dashboard-deepseek.timer` 跑一次（`dashboard-deepseek.service`，oneshot）。
- 数据文件：`.164:/opt/dashboard/deepseek.json`（当前值 + 今日/昨日消耗 + 近 14 天汇总）与 `deepseek-history.json`（余额点，保留 90 天，上限 5000 点）。
- 面板数据由监控台后端 `/api/stats` 新增的 `deepseek` 字段带出（`server.py` 里加了 `load_deepseek()`）。
- API Key 存在 `.164:/opt/dashboard/.deepseek-key`（600），**已加进 `/opt/homelab-git/sync.sh` 的排除名单，不会进 git 备份**。
