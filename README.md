本仓库所有文档均已脱敏：

- 域名统一替换为 `example.com`，公网 IP 替换为文档保留地址
- 内网 IP、Tailscale 地址、MAC 地址均已替换
- 邮箱、用户名、真实姓名已替换
- **密码、Token、API Key、Cookie、私钥等凭证全部删除或替换为 `<REDACTED>`**
